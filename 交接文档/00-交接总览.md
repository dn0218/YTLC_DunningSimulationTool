## 2. 系统简介

**Dunning（催缴/Collection）** 是计费系统的欠费管理模块：账户出账后若未在缴款期限内付款，系统按欠费天数逐级执行提醒、单停、双停、IMEI 黑名单、CTOS 黑名单、拆机等动作，并通过短信/邮件/Push 通知客户。

核心机制（基于 ZSmart Billing 的 Debit Rule 引擎）：

```
每日 JOB 扫描账户 → 命中 Rule Group（MASS/Enterprise/1BN/Auto-Dialer/Notification After Bill）
  → 逐条执行 Rule：跑 SQL 取数 → 数据赋值（Data Field/Variable）→ 判断条件
  → 命中则执行 Action（Notification / 单停 / 双停 / IMEI Block / CTOS / Termination ...）
  → 配置了 SCHED_TIME 的 Rule 生成 DEBIT_ACTION 记录，由第二个 JOB 延时执行
```

**Dunning 模拟工具（DunningTool_v4）**：测试环境专用 GUI 工具，通过改 `BILLING_CYCLE.DEBT_DATE` 等数据 + 触发生产同款 JOB，在几分钟内模拟任意欠费等级的完整催缴链路，替代过去手工等几十天的测试方式。
