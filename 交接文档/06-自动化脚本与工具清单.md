## 3. 出账模拟工具（Preprod_TestTool / Bill Run 流程）

| 项 | 说明 |
|----|------|
| 参考文档 | 工作区 `BILLING_PROCESS.md`（依据 `Preprod_TestTool.py` Core 1 真实源码整理的全流程 pseudo code） |
| 用途 | 测试环境模拟出账：检查账户 → RecurrRate 预计费 → `Brainless_Invoice.sh` 正式出账 → 核验发票/账单 |
| 关键步骤 | ① 账户三条件（存在/STATE='A'/POSTPAID='Y'）② 查 ±5 月账期 ③ SSH 逐号码跑 `RecurrRate -t <账期类型> -T -d <yyyymmdd> -e 1 -s <subs_id> -l 5`（必须 `bash -lc`）④ 校验 `EVENT_RECURRING_BC_xxx@link_rb` 整点行（缺一即中止）⑤ `./Brainless_Invoice.sh <BC_ID> <ACCT_ID>` ⑥ 30s 后核验 `e_invoice.E_INVOICE_NBR`、回拨 `SEND_DATE=SYSDATE-1`、解码 `bill_data_BC_xxx.BILL_CONTENT`(BLOB XML) 查 "null" |
| 关键判据 | 预计费行是否已生成：`TRUNC(EVENT_BEGIN_TIME)=EVENT_BEGIN_TIME`（零点整）；费用类型 ID 不可靠（同号码不同账期出现 12 和 4311） |
| 出账后动作 | 触发 `DebitActionJobNotificationAfterBill` 发出账短信（02 文档 §4.4） |

## 5. JOB 手动触发方法（HTTP）

任何环境都可 curl 直接触发（与工具同款接口）：

```bash
# Dunning 实例扫描（等价每日3点JOB）
curl -X POST "http://10.26.128.43:7000/jobservermgr/api/triggerJob?jobName=DebitActionJob&jobGroup=Collection&params=DEBIT_GROUP_TYPE=B|SP_ID=101"

# 动作执行（等价每日4/5/6点JOB）
curl -X Post "http://10.26.128.43:7000/jobservermgr/api/triggerJob?jobName=DebitActionDealJob&jobGroup=Collection&params=DEBIT_ACTION_DEAL,SP_ID=101"

# Auto-Dialer 扫描（等价每日8点JOB）
curl -X POST "http://10.26.128.43:7000/jobservermgr/api/triggerJob?jobName=DebitActionJobAutoDialer&jobGroup=Collection&params=DEBIT_RULE_GROUP_ID=11|SP_ID=101"

# 出账短信（出账后手动）
curl -X POST "http://10.26.128.43:7000/jobservermgr/api/triggerJob?jobName=DebitActionJobNotificationAfterBill&jobGroup=Collection&params=DEBIT_RULE_GROUP_ID=12|SP_ID=101|BILL_NOTIFY=Y"
```

> 注意 params 分隔符：DebitActionJob 系用 `|`，DebitActionDealJob 用 `,`（源码 api_manager.py 如此，保持一致）。
